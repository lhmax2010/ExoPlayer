# Data Structure Quick Reference

Last updated: 2026-05-18

This document is the direct lookup version of the bridge data-structure mapping.

Format rule:

- `Java DTO`: the DTO or transport object to search in the Java package.
- `C++ Struct`: the reduced struct to search in `include/exoplayer_bridge.h`.
- `JNI Create API`: the helper that converts C++ to Java.
- `JNI Parse API`: the helper that converts Java to C++.
- `SmokeTest`: the strongest current validation entry.
- `Smoke Test Status`: `Pass` means the smoke test has been run and passed on device; blank means not yet manually confirmed.
- `Smoke Test Command`: the exact `adb shell am instrument ...` command to rerun a passed smoke test quickly after code changes.

Note: the previous Chinese description column in this file was encoding-corrupted. The `Notes` column below has been rebuilt in English from the current reduced-model mapping and the main structure document.

Behavior note: pure lifecycle, listener-registration, and seek-navigation smoke cases are intentionally documented only in `API_MAPPING_QUICK_REFERENCE.md` when they do not validate a dedicated reduced DTO/struct payload.
