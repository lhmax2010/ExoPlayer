# API Mapping Quick Reference

Last updated: 2026-05-15

This document is the direct lookup version of the bridge API mapping.

Format rule:

- `Java API`: the method to search in `CppExoPlayerBridge.java`.
- `C++ API`: the method to search in `include/exoplayer_sdk.h`.
- `JNI API`: the real cross-language bridge entry that exists in code.
- `SmokeTest`: the strongest current validation entry; when there is no single dedicated test, this field points to the closest runtime or smoke coverage.
- `Smoke Test Status`: `Pass` means the smoke test has been run and passed on device; blank means not yet manually confirmed.
- `Smoke Test Command`: the exact `adb shell am instrument ...` command to rerun a passed smoke test quickly after code changes.
