## Player / ExoPlayer Method Gaps

- none

Name-level note: Java `Player.addListener` / `removeListener` map to the C++ standard
listener slot exposed as `SetListener` / `RemoveListener`. That standard slot is a
single delegate and `SetListener` replaces the previous delegate; analytics listeners
have a separate reduced multi-listener channel.
